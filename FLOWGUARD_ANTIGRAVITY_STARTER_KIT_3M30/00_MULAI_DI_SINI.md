1. Unduh ZIP starter ini. Buka Explorer dan ekstrak **ISI** ZIP langsung ke `P:\Demo Vid\`. Jangan ekstrak ke subfolder bernama ZIP, supaya struktur `P:\Demo Vid\00_MULAI_DI_SINI.md` terbentuk.
2. Buka Google Antigravity. Gunakan **Open Folder / Add Folder**, pilih `P:\Demo Vid`, lalu gunakan agent dalam **Local** mode dengan Gemini Flash Thinking High jika model tersebut tampil di akunmu. Tidak perlu membuka repository asli FlowGuard AI.
3. Buka `02_PROMPT_GEMINI_ANTIGRAVITY.md`; **salin seluruh isinya** ke chat agent Antigravity. Lampirkan/referensikan path berkas ini jika agent mendukung pembacaan langsung.
4. Izinkan instalasi dependensi npm wajar di `P:\Demo Vid\remotion-project` saja setelah meninjau perintahnya. Remotion mengikuti `https://www.remotion.dev/docs/`; agent menjalankan terminal dan memverifikasi preview sebelum membuat semua adegan.
5. Setelah hasil preview/potongan video tersedia, kirim screenshot/hasil render ke GPT-6 untuk audit sinematik dan kebenaran bukti.
